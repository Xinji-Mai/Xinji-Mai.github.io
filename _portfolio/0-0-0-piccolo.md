<p class="i18n-en">Piccolo is a family of 4B, 9B, and 27B decision models. Given a state, a question, and candidate options, it returns structured decisions and candidate probabilities for tool review, context retention, data workflows, and interactive environments.</p>
<p class="i18n-zh">Piccolo 是包含 4B、9B 与 27B 的决策模型系列。模型根据状态、问题和候选选项，返回结构化决策与候选概率，适用于工具调用审核、上下文保留、数据工作流与交互环境。</p>
<p class="i18n-en">The project connects diagnosis, data selection and construction, training, and evaluation in an iterative loop. Its repository includes inference code, evaluation tools, workflow examples, and an interactive Arena. Model releases include Safetensors weights and BF16, Q8_0, and Q4_K_M GGUF versions.</p>
<p class="i18n-zh">项目通过诊断、数据筛选与构建、训练和评测形成迭代闭环，仓库提供推理代码、评测工具、工作流示例与交互式 Arena。模型提供 Safetensors 权重及 BF16、Q8_0、Q4_K_M 格式的 GGUF 版本。</p>
